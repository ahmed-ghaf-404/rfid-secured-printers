# 🖥️ الواجهة الأمامية لمشروع الطباعة باستخدام RFID (React)

## ✅ المتطلبات:
- Node.js
- npm

---

## ⚙️ خطوات التشغيل:

```bash
cd frontend
npm install
npm run dev
```

> يقوم الأمر الأول بتثبيت الحزم، والثاني بتشغيل الخادم المحلي

---

## 🌍 رابط الوصول:

```
http://localhost:3000
```

---

## 🖨️ الوظائف:

- إدخال رقم بطاقة RFID
- تحميل ملف للطباعة
- إرسال الملف للطابعة عبر الباك إند

---

## 📝 ملاحظات:

- تأكد من تشغيل الباك إند أولًا (FastAPI) على المنفذ `8000`
- الطباعة تتم على طابعة مربوطة بجهاز Windows
- يُفضل استخدام متصفح حديث مثل Google Chrome
