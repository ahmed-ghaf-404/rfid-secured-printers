## Version 1.0 scope

RFID-controlled printing across supported printer brands, with compatibility verified by model.

The first release targets:

- PDF document submission.
- Modern network printers.
- One supported RFID reader and card combination.
- An external release station where users scan their card to release held print jobs.

Specific supported printer models and RFID hardware will be listed after testing.

Support for older printers and USB-connected printers is planned for later releases through tested integrations.
